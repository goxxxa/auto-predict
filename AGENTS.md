# Auto Predict

Учебный проект по прогнозированию цены объявлений о продаже подержанных
автомобилей. Основная модель — интерпретируемая ANFIS Сугено первого порядка.
Эксперимент сравнивает градиентное обучение ANFIS, генетическую настройку
ANFIS и классические регрессоры. Целевая переменная — цена объявления в рублях
(`price_rub`). [План проекта](PROJECT_PLAN.md)

## Работа с репозиторием

- Управляй окружением через `uv`. Диапазон Python 3.12 задан в
  `pyproject.toml`, версии зависимостей зафиксированы в `uv.lock`.
  Обычный `uv run` использует существующий lock-файл и обновляет его,
  если конфигурация зависимостей изменилась.
- Храни импортируемый код в `src/auto_predict/`, а точки запуска экспериментов
  в `scripts/`. Скрипты разбирают аргументы и вызывают функции пакета.
- Используй pandas для чтения, очистки и разбиения табличных данных.
  Сохраняй код простым, переиспользуй загрузку данных, разбиение, метрики и
  построение графиков.
- Для обучения ANFIS используй `--extra gpu`. На Windows и Linux он подключает
  PyTorch с CUDA 12.8 из официального индекса. Обучение обеих версий проверено
  на NVIDIA GeForce RTX 3050 с 8 ГБ видеопамяти и PyTorch 2.11.0+cu128.
- Храни исходный архив в `data/raw/`, результаты экспериментов в
  `data/processed/`. Каталог `data/` и вузовский отчёт исключены из Git.
  Графики завершённого эксперимента сохранены в [figures/](figures/).

## Данные и разбиение

Использована [ревизия 80648d4 архива Drom.ru](https://huggingface.co/datasets/zavzyatiy/cars_from_drom.ru_archive_2007-2025/tree/80648d4)
с основным файлом `drom_archive_2007-2025_full_27-07-2025.csv` размером около
5,4 ГБ. Словарь `DROM_COLUMN_NAMES` связывает исходные заголовки с полями
проекта и задаёт колонки для `usecols`. Pandas читает архив по 100 000 строк
за порцию. Из него отбираются объявления Kia Rio за 2022–2025 годы,
удаляются дубли по ссылке, проверяются числовые значения и рассчитывается
возраст на дату публикации.

В рабочей выборке **63 391 объявление** с 1 января 2022 по 12 июля 2025 года.
У 544 объявлений отсутствует валидный пробег. Возраст и мощность заполнены
во всех строках. Признаки всех моделей — `age_years`, `mileage_km` и
`power_hp`. Пропуски заполняются медианами обучающей части. Для Ridge и
ANFIS признаки дополнительно стандартизируются.

На 55 336 объявлениях за 2022–2024 годы проводится кросс-валидация по пяти
временным фолдам через `TimeSeriesSplit`. Сначала делятся уникальные даты,
затем по ним отбираются строки. Обучающее окно расширяется, а следующий
блок дат служит валидацией. 8 055 объявлений 2025 года образуют отложенный
тест. Подбирай параметры только на данных до границы теста. Для
сопоставимости экспериментов используй те же признаки, даты и метрики.

## Что обучено

- **Классические модели.** Медианный прогноз, Ridge, Random Forest и
  Gradient Boosting оценены на тех же пяти фолдах и тесте. У случайного
  леса минимум пять наблюдений в листе. Бустинг обучается с абсолютной
  ошибкой. Для обеих моделей задан `random_state=42`.
- **ANFIS.** Две гауссовы функции принадлежности на каждый из трёх входов
  дают восемь правил с линейными выводами. Центры инициализируются
  квартилями обучающей части. Adam обновляет центры и ширины, а
  регуляризованный метод наименьших квадратов обновляет выводы правил.
  Оба шага идут на GPU. По среднему MAE пяти фолдов выбрана 120-я эпоха
  из 120 проверенных. Финальная модель обучена на данных 2022–2024 годов.
- **ANFIS + GA.** Генетический алгоритм подбирает центры и логарифмы ширин
  при той же базе правил. Поиск оценивает 20 кандидатов за поколение,
  проходит 35 поколений и повторяется с seed 17, 42 и 79. В каждом
  обучающем окне ранние 80% уникальных дат используются для расчёта
  линейных выводов, последние 20% — для внутренней валидации.
  После выбора кандидата линейные выводы переоцениваются на всём
  обучающем окне. Этот же порядок применяется на всех данных до 2025 года
  для финального теста.
- **Интерпретация.** Сопоставлены функции принадлежности обеих ANFIS.
  Для восьми правил ANFIS + GA рассчитаны средние веса, доли объявлений,
  где правило имеет максимальный вес, и линейные коэффициенты в исходных
  единицах. Для трёх объявлений показано, как вклады правил складываются
  в прогноз.

## Результаты

| Модель | Средний MAE валидации, ₽ | MAE теста, ₽ | RMSE теста, ₽ |
|---|---:|---:|---:|
| Random Forest | 206 314 | 193 500 | 253 228 |
| ANFIS + GA | 208 430 | 197 267 | 251 087 |
| ANFIS | 212 173 | 202 388 | 255 692 |
| Gradient Boosting | 216 828 | 206 986 | 266 453 |
| Ridge | 223 330 | 210 162 | 261 599 |
| Медианный прогноз | 345 983 | 320 813 | 411 861 |

Random Forest показал минимальный MAE. Генетическая настройка снизила MAE
ANFIS на тесте на 5 121 ₽, или 2,5%. В измеренном запуске кросс-валидация
вместе с финальным обучением заняла 14,5 с для ANFIS и 6,0 с для ANFIS + GA
при указанных настройках.

Четвёртый фолд (3 января — 2 июля 2024 года) дал наибольший MAE валидации
у всех моделей. Медианная цена в нём выросла с 808 000 ₽ в обучающей части
до 1 050 000 ₽ в валидационной. У ANFIS средний MAE валидации по эпохам
снизился с 217 168 до 212 173 ₽, поэтому разрыв между обучением и валидацией
стоит рассматривать с учётом изменения данных во времени. Текущий вывод
относится к объявлениям Kia Rio. Удаление дублей по ссылке покрывает
повторяющиеся ссылки, а разные объявления одного автомобиля могут
остаться в выборке.

## Воспроизведение

Запускай команды из корня репозитория. Для предобработки нужен локальный CSV
из указанной ревизии архива.

```powershell
uv sync --extra gpu
uv run --extra gpu python scripts/prepare_data.py data/raw/drom_archive_2007-2025_full_27-07-2025.csv
uv run --extra gpu python scripts/evaluate_baselines.py data/processed/listings.csv
uv run --extra gpu python scripts/train_anfis.py data/processed/listings.csv
uv run --extra gpu python scripts/train_anfis_genetic.py data/processed/listings.csv
uv run --extra gpu python scripts/compare_anfis.py data/processed/listings.csv
```

Все пути ниже относительны к `data/processed/`.

| Путь | Содержимое |
|---|---|
| `listings.csv`, `quality_by_year.csv` | Очищенная выборка и годовая сводка |
| `baselines.csv`, `baselines_validation.png`, `baselines_test.png` | Метрики и графики классических моделей |
| `anfis/` | История MAE по эпохам, тестовые метрики, графики и `model.pt` |
| `anfis_genetic/` | Ход поиска по поколениям, метрики фолдов и теста, графики и `model.pt` |
| `anfis_comparison/` | Сводное сравнение, графики функций принадлежности, `rules.csv` и `examples.csv` |

В каждом `model.pt` хранятся параметры сети, порядок признаков, медианы и
параметры стандартизации, а также коэффициент пересчёта прогноза в рубли.
По умолчанию повторные эксперименты сохраняют результаты в те же каталоги.
Для отдельного прогона задай выходной путь аргументом скрипта.

Интерактивная точка входа в корне проекта запускается через
`uv run --extra gpu python main.py`. Она использует готовую
модель ANFIS + GA на CPU и запрашивает возраст Kia Rio, пробег и мощность.
