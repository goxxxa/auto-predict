# Прогноз цены подержанных автомобилей с помощью ANFIS

Модель прогнозирует цену объявления в рублях. Эксперимент оценивает точность
ANFIS и эффект генетической настройки функций принадлежности.

1. Зафиксировать ревизию [архива Drom.ru](https://huggingface.co/datasets/zavzyatiy/cars_from_drom.ru_archive_2007-2025)
   и сверить описание колонок. Читать архив через pandas с `usecols` и
   `chunksize`. Свести количество объявлений и пропуски по моделям и годам.
   Проверить Kia Rio за 2022–2025 годы как стартовый сегмент и сохранить
   выбранные строки в CSV.
2. Очистить некорректные значения и дубли. Рассчитать возраст на дату
   объявления. Отложить последний период для теста и провести временную
   кросс-валидацию на пяти фолдах с расширяющимся окном обучения. По
   возможности исключить пересечения повторных публикаций одного авто.
   Оценивать параметры предобработки по обучающей части каждого фолда.
3. Сравнить ANFIS с медианным прогнозом, Ridge, случайным лесом
   (Random Forest) и градиентным бустингом (Gradient Boosting).
   Использовать один набор признаков и одинаковое временное разбиение
   для всех моделей. Основная метрика — MAE в рублях. Дополнительные
   метрики — RMSE и медианная абсолютная ошибка. Показать MAE обучения
   и валидации по фолдам, а на тесте сопоставить прогнозы с ценами объявлений.
4. Реализовать ANFIS Сугено первого порядка на PyTorch с CUDA. Начать с
   возраста, пробега и мощности, по две гауссовы функции принадлежности
   на признак. Восемь правил обучать гибридным методом, сочетая наименьшие
   квадраты для линейных выводов и градиент для функций принадлежности.
5. При той же структуре правил подобрать их центры и ширины генетическим
   алгоритмом. Оценивать кандидатов на отдельном периоде внутри обучающей
   части каждого фолда. Повторить поиск с несколькими seed, зафиксировать
   время обучения и сравнить модели на отложенном тесте.
6. Построить графики функций принадлежности, выписать правила и оценить
   их покрытие. Объяснить несколько прогнозов через веса активных правил.
   По желанию добавить форму оценки цены.

Первый результат работы с данными — воспроизводимая команда подготовки
CSV и сводка по числу строк, пропускам и ценам. По ней утверждаются сегмент
и даты разбиения.

## Запуск подготовки данных

Скачайте основной CSV архива в `data/raw` и запустите из корня проекта:

```powershell
uv run python scripts/prepare_data.py data/raw/drom_archive_2007-2025_full_27-07-2025.csv
```

По умолчанию команда выбирает Kia Rio за 2022–2025 годы и записывает
`listings.csv` и `quality_by_year.csv` в `data/processed`. Сегмент можно
изменить через `--model`, `--start-year` и `--end-year`.

## Сравнение базовых моделей

```powershell
uv run python scripts/evaluate_baselines.py data/processed/listings.csv
```

Объявления 2022–2024 годов делятся через `TimeSeriesSplit` по датам
публикации. В каждом из пяти фолдов обучение охватывает все предыдущие
даты, а валидация — следующий блок дат. Пропуски заполняются медианами
обучающей части фолда. Для оценки объявлений 2025 года модели заново
обучаются на всех данных до 2025 года.

В `data/processed` сохраняются `baselines.csv` с метриками и датами
периодов, `baselines_validation.png` с MAE по фолдам и `baselines_test.png`
с прогнозами на тесте. Число фолдов и границу теста можно задать через
`--folds` и `--test-start`.

## Обучение ANFIS на GPU

```powershell
uv run --extra gpu python scripts/train_anfis.py data/processed/listings.csv
```

GPU-окружение для Windows и Linux использует сборку PyTorch с CUDA 12.8.
На каждом временном фолде заполнение пропусков и стандартизация вычисляются
по обучающей части. В каждом цикле Adam обновляет параметры функций
принадлежности, а регуляризованный метод наименьших квадратов подбирает
линейные выводы правил. Оба шага выполняются на GPU.

Число эпох выбирается по среднему MAE на пяти валидационных фолдах.
Финальная модель обучается на всех объявлениях до 2025 года и оценивается
на отложенном тесте. Результаты сохраняются в `data/processed/anfis`
вместе с графиками и весами модели.

## Генетическая настройка и сравнение

```powershell
uv run --extra gpu python scripts/train_anfis_genetic.py data/processed/listings.csv
uv run --extra gpu python scripts/compare_anfis.py data/processed/listings.csv
```

Каждый поиск использует популяцию из 20 кандидатов, 35 поколений и три
запуска с seed 17, 42 и 79. Хромосома задаёт центры и логарифмы ширин
гауссовых функций. Популяция оценивается параллельно на CUDA. Для каждого
кандидата линейные выводы подбираются на ранних 80% дат тренировочного
периода. MAE считается на оставшихся 20% дат этого периода.

Победитель выбирается по внутреннему MAE. Его линейные выводы затем
переобучаются на всей обучающей части фолда, сохраняя параметры функций
принадлежности и масштабирование признаков. Для теста 2025 года та же
процедура выполняется на объявлениях 2022–2024 годов.

В `data/processed/anfis_genetic` сохраняются метрики, ход поиска по
поколениям, графики валидации и теста и файл модели. Сравнение обеих
версий ANFIS с классическими моделями, графики функций принадлежности,
коэффициенты восьми правил в исходных единицах и три примера прогнозов
сохраняются в `data/processed/anfis_comparison`. Время в отчёте ANFIS
включает кросс-валидацию и финальное обучение на одном GPU.

## Обучение ANFIS на недавних объявлениях

```powershell
uv run --extra gpu python scripts/train_anfis_genetic.py data/processed/listings.csv --lookback-months 0 2 3 6 9 12 18
uv run python scripts/evaluate_baselines.py data/processed/listings.csv --lookback-months 2
```

На тех же пяти фолдах сравнивается вся доступная история (`0`) и окна от
2 до 18 месяцев перед валидацией. Побеждает окно с наименьшим средним MAE
валидации. Для теста 2025 года модель обучается на выбранном окне перед
началом тестового периода.

Наилучший результат дало окно в два месяца. Финальная модель использовала
3 065 объявлений ноября и декабря 2024 года. Тестовый MAE снизился с
197 267 до 130 310 ₽, а MAE на пяти фолдах — с 208 430 до 133 691 ₽.
Метрики, выбор окна, графики и веса сохранены в
`data/processed/anfis_genetic_recent`.

На том же двухмесячном окне Gradient Boosting получил тестовый MAE
126 791 ₽, а Random Forest — 134 827 ₽. Метрики классических моделей
сохранены в `data/processed/baselines_recent.csv`.

## Расширенный подбор гиперпараметров

Все параметры подбираются по среднему MAE на пяти временных фолдах
до 2025 года. Тест 2025 года используется как исторический бенчмарк,
который уже применялся в предыдущих экспериментах.

```powershell
uv run python scripts/prepare_data.py data/raw/drom_archive_2007-2025_full_27-07-2025.csv --vehicle-details
uv run --extra gpu python scripts/tune_anfis.py data/processed/listings.csv
uv run --extra gpu python scripts/tune_anfis.py data/processed/extended/listings.csv --refine-from data/processed/tuning/anfis/validation_trials.csv --output-dir data/processed/tuning/anfis_extended
uv run --extra gpu python scripts/tune_anfis.py data/processed/extended/listings.csv --refine-from data/processed/tuning/anfis_extended/validation_trials.csv --add-generation --output-dir data/processed/tuning/anfis_vehicle
uv run python scripts/tune_trees.py data/processed/extended/listings.csv
uv run python scripts/tune_trees.py data/processed/extended/listings.csv --refine-from data/processed/tuning/trees/validation_trials.csv --output-dir data/processed/tuning/trees_refined
uv run --extra boost python scripts/tune_trees.py data/processed/extended/listings.csv --catboost --output-dir data/processed/tuning/catboost
uv run --extra boost python scripts/tune_trees.py data/processed/extended/listings.csv --catboost --refine-from data/processed/tuning/catboost/validation_trials.csv --output-dir data/processed/tuning/catboost_refined
uv run --extra gpu --extra boost python scripts/evaluate_tuned_blend.py data/processed/extended/listings.csv
```

В ANFIS проверены окна в календарных днях, регуляризация линейных выводов,
логарифм цены, затухание веса давних объявлений, мутации, размеры популяции
и число правил. Отдельно проверены представление возраста, логарифм пробега,
коробка передач и поколение автомобиля. Выбранная ANFIS использует год
выпуска, логарифмический пробег, мощность, АКПП и поколение, всего 32
правила. Она обучена на последних 90 днях с периодом полураспада веса
10 дней, штрафом 0,00003, популяцией из 20 кандидатов и 35 поколениями.
Её MAE составил 114 795 ₽ на валидации и 120 434 ₽ на тесте.

Для деревьев проверены глубина, длина окна, размер листа, регуляризация,
скорость и число итераций, функция потерь, признаки региона и автомобиля,
веса по давности и поправка по недавним остаткам. Для смеси ANFIS,
гистограммного бустинга и CatBoost веса перебираются с шагом 0,1 по тем же
валидационным фолдам. Рейтинги вариантов, метрики и графики находятся в
`data/processed/tuning/`.

Гистограммный бустинг с признаками автомобиля и региона получил
109 998 ₽ MAE на фолдах и 118 359 ₽ на тесте. Первичный подбор CatBoost дал
116 657 ₽ на фолдах и 116 249 ₽ на тесте. Дополнительная настройка CatBoost
снизила MAE на фолдах до 109 896 ₽, а на тесте ошибка выросла до 135 355 ₽.
Смесь получила 107 232 ₽ на фолдах и 123 857 ₽ на тесте. Подбор её весов
оставил по 0,5 гистограммному бустингу и CatBoost.

В дополнительных опытах взвешенная оценка по ближайшим соседям дала
147 068 ₽ MAE на тесте. Аддитивная модель со сплайнами и регрессией Хьюбера
дала 120 251 ₽ после повторной проверки с увеличенным бюджетом оптимизации.
Их результаты сохранены в `neighbors_trials.csv` и `spline_metrics.csv`
в каталоге подбора.

## Оценка цены из терминала

```powershell
uv run --extra gpu python main.py
```

Точка входа загружает наиболее полный сохранённый вариант ANFIS + GA,
запрашивает его входные признаки, рассчитывает прогноз на CPU и показывает
три правила с наибольшим весом. Для модели с 32 правилами вводятся год
выпуска, пробег в километрах, мощность в лошадиных силах, тип коробки и
поколение Kia Rio. Если поколение неизвестно, нажмите Enter. Тогда
используется медианное поколение из обучающих данных.
